# Crafting terminology

UI simplification vocabulary for U-08. Keep these names stable across the Forge, item sheets, Recipes, Guide and previews.

| English term | Use it for | Player-facing outcome |
| --- | --- | --- |
| Personal Infusion | Binding an essence permanently to the character in Gear | Trait remains active with any equipment; separate from gear Infuse. |
| Infuse gear | Forge action that binds an essence to an item | Changes that item's traits; consumes the item and essences shown in the preview. |
| Improve gear | Forge action that changes an item with materials | Adds or changes traits; exact inputs and result appear in the preview. |
| Refine | Forge grade panel | Combines matching materials or essences to raise their grade. |
| Reforge | Repair a flawed crafted item | Spends embers to remove mishaps or restore weakened traits. |
| Deconstruct | Process raw finds, food, potions, herbs or relics | Produces base materials and/or essence fragments; eligible raw finds can yield full essences. |
| Salvage | Break crafted gear for materials and essences | Returns the listed materials and bound essences; bulk salvage always has a review step. |
| Pattern | Generic gear recipe made from base materials | Choose a form, then fill its material slots. |
| Blueprint | Named gear recipe learned by studying creatures | Uses its named gear recipe and base-material slots. |
| Recipe | A combination the player has forged and can load again | Records the actual ingredients and result. |

German distinguishes raw-find **Aufbereiten** from gear **Zerlegen**; Korean uses **가공** for Deconstruct and **분해** for Salvage. Patterns and blueprints retain separate translated names. Preserve the existing action IDs, recipe data, gates and save fields when changing these labels.
